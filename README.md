# SWE-CoWork

SWE-CoWork evaluates coding agents on tasks that require gathering requirements
from a simulated workplace. This repository hosts the 101 Harbor tasks used by
the [PenguinHarness integration](https://github.com/Prism-Shadow/penguin-harness-benchmark/pull/36).
